# RentalCar# RentalCar — frontend (Next.js + TypeScript)

Коротко: фронтенд частина тестового завдання для компанії RentalCar. React + Next.js App Router, Zustand для стану.

Функції:

- Головна сторінка з банером
- Каталог автомобілів з фільтрами (бренд, ціна, пробіг)
- Пагінація "Load More" (серверна пагінація)
- Сторінка детальної інформації + форма бронювання
- Збереження обраних в localStorage

Інструкції:

1. `npm install`
2. `npm run dev`
3. Відкрийте http://localhost:3000
