🚗 RentalCar – Car Rental Platform
RentalCar is a modern car rental web application that allows users to effortlessly browse, filter, and book vehicles online. Designed with a focus on user experience, it combines sleek design with robust functionality.

🌟 Key Features
Home Page – Eye-catching banner with call-to-action for quick access to the catalog.
Catalog Page – Browse all available vehicles with advanced filtering options by:

Brand
Price per hour

Mileage
Load More Pagination – Seamlessly load additional vehicles without leaving the page.
Vehicle Detail Page – Detailed information about each vehicle including images, specifications, and booking form.
Booking Form – Reserve a car with date selection (past dates disabled) and optional comments.
Favorites List – Save preferred vehicles for easy access, persistent across sessions.
Responsive Design – Works beautifully on desktop and mobile devices.

🛠 Technologies Used
Next.js – React framework for server-side rendering and routing
React & TypeScript – Modern frontend stack for maintainable and type-safe code
Zustand – State management for vehicles, filters, and favorites
Axios – API requests to backend
iziToast – User notifications for booking and interactions
next/image – Optimized image rendering for faster load times

🚀 Getting Started
git clone https://github.com/yourusername/rentalcar.git
npm install
npm run dev
Open http://localhost:3000
in your browser.

/components – Reusable React components
/store – Zustand state management

/public – Static assets (images, icons)
