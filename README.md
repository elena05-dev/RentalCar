Car Rental Website

This project is a car rental platform that allows users to browse available vehicles, filter them by brand, price, and mileage, and book a car directly from the website. Key features include:

Home page with a banner and call-to-action button.

Catalog page displaying all vehicles with filtering options and “Load More” pagination.

Vehicle detail page with detailed information, images, and a booking form.

Favorites list to save preferred vehicles, which persists across page reloads.

State management using Zustand to handle vehicles, filters, and favorites.

The website is built with Next.js, React, and TypeScript, and includes responsive UI components and optimized images using next/image.
